# admin-web

个人网站 Admin 管理后台前端（React + Vite SPA）。

## 项目作用

- 系统监控：CPU / 内存 / 磁盘 / 网络实时与历史趋势、服务状态、软件版本
- 博客管理：文章 / 合集增删改查
- 管理：登录设备会话、接口令牌、重置验证器
- 终端：浏览器内连接服务器终端
- 文件：资源管理器式文件区（目录导航 / 上传 / 下载 / 临时链接）
- 通知：通知中心 / 通知管理 / 调试

## 登录

默认自带账号口令，开箱即用；也可以关掉自带口令。

| 模式 | 说明 |
|---|---|
| `builtin` | 默认。自带账号口令（本服务自己的登录页与会话） |
| `sso` | 关掉自带口令，管理端身份由 `X-Auth-User` 决定——自家项目接 SSO 时走这一档 |

模式由服务端环境变量 `AUTH_MODE` 决定，前端启动时自动探测。
关掉后的登录跳转与 401 由你前面的认证层决定，本服务不再展开。

## 配置

构建时环境变量（真实值只写在本地 `.env`，仓库只留 `.env.example` 占位）：

- `VITE_HERMES_DASHBOARD_URL`：侧栏「Hermes」页 iframe 指向的地址
- `VITE_SITE_URL`：公共站点基址，博客链接据此拼绝对地址

## 命令

```bash
npm install
npm run dev      # Vite 开发服务器，接口代理到后端
npm run build    # 构建（输出目录由 vite 配置指定）
npm run preview
```

构建产物目录在 `vite.config.js` 的 `build.outDir` 中指定，按自己的部署调整即可。
