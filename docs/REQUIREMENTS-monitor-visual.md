# 需求：监控页视觉重构（多图表 + 信息层级）

日期：2026-10-20
用户：「多用一些图表，监控这一块做美观一点，参照任何你想参照的产品，反正一定要好看」

参照对象：Grafana 的信息密度、Vercel 的克制留白、Ant Design 的默认语言。
**不引新依赖**（echarts 6 已装，`Chart.tsx` 已按需注册折线/网格/提示/缩放/图例）。

## 一、当前问题（截图可见）

1. 只有一张内存进度条，**没有任何趋势图**
2. 布局松散：三张卡高度不齐，`Top 进程 / 失败单元 / 最近登录` 挤成两列窄栏，文字被截断
3. 页面底部出现**横向滚动条**（内容溢出视口）
4. 数字无等宽字体，刷新时宽度跳动
5. 「最近登录采集失败」用告警色常驻，属于噪声
6. 更新时间孤立飘在右上角

## 三、图表要求（都要真数据，不要装饰）

### 1. KPI 迷你趋势（sparkline）
- 5 张卡各带 40×28 的极简折线（最近 60 个采样点）
- 无坐标轴、无网格、无标签，线宽 1.5，下方 8% 透明度渐变填充
- 颜色：主色单色；超过阈值（如 CPU>85、内存>90、磁盘>85）才切 warning/error

### 2. 主趋势图（echarts）
- 双系列：CPU%（左轴 0–100）、内存%（右轴 0–100）
- 时间范围切换：`1h / 6h / 24h / 7d`（对应现有 `/api/admin/system/metrics?range=&step=`）
- 面积渐变、`smooth: 0.25`、`symbol: none`
- `dataZoom` 只留内部缩放，不要滑条（省空间）
- 无网格线纵轴、横轴仅 4–6 个时间刻度
- tooltip：轴触发，显示时间 + CPU + 内存

### 3. PSI 压力条
- 三个横向条（cpu / io / memory），显示 `some.avg60`
- 宽度按 0–100 映射，颜色按档位（<20 主色、20–50 warning、>50 error）
- 条右侧给数值（保留 2 位小数）

### 4. 卡顿指数
- 大数字 + 圆点 + 档位文字（顺畅/有压力/明显卡顿）
- 副行：「过去 60 秒有 X% 的时间在等 CPU」

## 四、视觉规则（硬约束）

| 项 | 规则 |
|---|---|
| 数字 | `font-variant-numeric: tabular-nums`，统一 1 位小数（PSI 2 位） |
| 字号 | KPI 28px/500，label 12px 次级色，正文 13px |
| 卡片 | `bordered`、圆角 8、内边距 16，同一行等高（align stretch） |
| 间距 | 8px 基准；卡片间 16px；区块间 24px |
| 颜色 | 只用 antd 状态色；图表单色 + 渐变，**不要彩虹配色** |
| 装饰 | 不要卡片阴影、不要彩色渐变进度条、不要图标堆砌 |
| 空态 | 无数据时显示 `—`，不显示 0，不显示告警色 |
| 暗色 | 跟随 antd 算法；图表在主题切换时重建（订阅 `subscribeTheme`） |
| 移动端 | ≤768px：KPI 两列、图表全宽、表格横向可滚，**整页不得出现横向滚动条** |

## 五、验收

1. 页面无横向滚动条（`document.documentElement.scrollWidth <= innerWidth`，390 / 768 / 1440 三档都验）
2. KPI 5 张卡等高，数字列宽不随刷新跳动
3. 主趋势图能切 1h/6h/24h/7d，切换后请求参数与返回点数匹配
4. `yes` 尖峰时：KPI CPU 上升、sparkline 出现尖刺、卡顿指数上升
5. PSI 三条与 `/proc/pressure/*` 的 avg60 一致（±0.1）
6. 暗色模式下图表文字/轴线可读（贴暗色截图）
7. 失败单元为 0 时不显示红色；最近登录采集失败降级为灰色说明文字
8. `npm run build` + typecheck 通过，无新增依赖（`package.json` 不变）
9. 贴 1440 / 768 / 390 三张截图
